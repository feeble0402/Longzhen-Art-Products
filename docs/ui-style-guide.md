# UI Style Guide

Public UI references the information hierarchy and section rhythm of Rakuten L.O.V.E without copying assets.

| Token | Value | Use |
|---|---|---|
| `brand-agarwood` | `#5A3C28` | primary text and dark surfaces |
| `brand-golden-wood` | `#B68142` | CTA and accents |
| `brand-linen` | `#F2E8D8` | main light background |

Create accessible semantic derivatives after contrast testing. Tailwind is limited to public brand UI; Element Plus is limited to admin features.
